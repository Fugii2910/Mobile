# tutorial051

Descrição: Esse projeto foi um conjunto de vários componentes de seleção, programando cada um e vendo suas definições e modo de uso, no final a tela tinha todos os 8 componentes, CheckBox (Seria a parte de poder marca as opções que tem, podendo tem mais que uma marcação), Chip (Funciona como um filtro de pequisa), DatePicker (Acaba sendo o calendario para marcar algum compromisso), Menu (espaço para escolher a opção que gostaria), Radio (Seria a parte de poder marca as opções que tem, porem podendo escolher apenas uma), Slider (Seria o espaço que tem de deslizar para a quantidade ou mesmo o próprio volume do dispositivo), Switch (Funciona como um interrupitor, com a função de ligar e desligar a opção) e TimePicker (Aqui é arrumar uma hora para seu compromisso).
